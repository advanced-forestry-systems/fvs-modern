# Species-free modifier eta interface

The 25 calibrated variant configs contain six `categories_conus_sf_modifier` blocks. The checked projector does not apply them. `FvsConfigLoader.sf_modifier_fixed_eta()` now evaluates their **fixed-effect correction to the base linear predictor** for an explicitly supplied condition. It does not activate modifiers in the engine or change existing projections.

The caller supplies all eight observed 0/1 indicators (`plant`, `fire`, `insect`, `disease`, `wind`, `harvest`, `cutting`, `siteprep`) and both decay envelopes as finite values from 0 to 1. The plantation term is not decayed. Disturbance and treatment terms use their respective envelopes. For HCB, an active trait-mediated term also requires all eight raw traits; the loader applies the stored centering and scaling before the gamma dot product. Missing indicators or required traits raise an error. The returned value includes `alpha_0` even when every indicator is zero.

The fit was `eta_total = eta_base + delta`. Apply `delta` **before the component's inverse link**. A final-output multiplier is not generally equivalent for logit-linked components. The JSON note that says `exp(alpha_0 + alpha[type])` is an incomplete description of the fitted model: multiple indicators can enter, disturbance and treatment effects decay, and HCB can vary with species traits.

This interface omits the fitted Level 1 random effect because the current JSON block does not contain it. The block also omits an explicit decay constant; callers must supply the same decay envelopes used in fitting. It is a population-level fixed-effect evaluator, not a complete projection integration. Activation needs an audited condition-to-event mapping, source convergence review, component-level inverse-link and sign checks, seeded engine parity, and held-out disturbed and treated plot validation. See the [Cardinal source and stress review](https://github.com/holoros/fvs-conus-pipeline/blob/main/MODIFIER_INTEGRATION_REVIEW_2026-11-25.md).
