# config/catalog

`catalog_recommendation_by_variant.csv` and `catalog_gates_by_arm.csv` are the fvs-modern configuration catalog, read by `fvs2py.catalog.select_config(variant)`. They were regenerated on the evening of October 29, 2026 (fourth version: the stand generator no longer fills null TPA_UNADJ records with 6.0 trees per acre, so every sampled stand passes the year-0 gate; no verdict changed from the third version) by `validation/bakuzis_stress_v2/catalog/` (`gates_v5/`; see its README for the stand sample, the thresholds, the pre-registered rule, the stress-test alternative and the seeding fix). Regenerate them only through that pipeline; do not edit by hand. `status` and `recommended` follow the primary rule, which is the rule the catalog ships under (decision of October 29, 2026); `admissible_alt` and `rule_sensitive` show the alternative.
