# config/catalog

`catalog_recommendation_by_variant.csv` and `catalog_gates_by_arm.csv` are the fvs-modern configuration catalog, read by `fvs2py.catalog.select_config(variant)`. They were regenerated on October 30, 2026 (sixth version, catalog v8, from `validation/bakuzis_stress_v2/catalog/gates_v8/`, stress labels from `stress_v8/`; pull requests 144 and 145). In the sixth version all four arms were rerun after the expansion of condition trees was corrected to the condition's share of each plot size (MICRPROP_UNADJ, SUBPPROP_UNADJ, MACRPROP_UNADJ) rather than CONDPROP_UNADJ alone (defect D5; 266 of 4,748 stands seeded more than 2 percent differently). No primary rule verdict, recommended arm or status changed; WC default and calibrated GOMPIT are no longer admissible under the alternative rule, so WC is no longer rule sensitive, and WS calibrated native is now stable admissible (`validation/bakuzis_stress_v2/catalog/catalog_v6_v8_verdict_changes_full.csv`). The fifth version was regenerated on October 30, 2026 by `validation/bakuzis_stress_v2/catalog/` (`gates_v6/`; see its README for the stand sample, the thresholds, the pre-registered rule, the stress-test alternative and the seeding fix). In the fifth version the calibrated arms (native and GOMPIT survival, all 18 variants, the same 300-stand sample and seed) were rerun with the fix in PR 135: the in-process calibrated overlay had written a maximum SDI of 0 for species without a calibrated value, which changed calibrated trajectories in CA, CR, CS, EM, LS and WC. The default arms are unaffected by that fix and are carried over from the fourth version. Verdict changes from the fourth version (`validation/bakuzis_stress_v2/catalog/catalog_v5_v6_verdict_changes.csv`): the least-bad arm named for EM is now conus_b2_gompit (was calibrated_gompit) and for WC default_gompit (was calibrated_gompit), both still NOT RECOMMENDED for long horizons; WC calibrated_gompit becomes admissible under the alternative rule; the NE calibrated_native stress verdict moves from FRAGILE to STABLE admissible. No status and no primary-rule admissibility changed.

The fourth version (evening of October 29, 2026) made the stand generator stop filling null TPA_UNADJ records with 6.0 trees per acre, so every sampled stand passes the year-0 gate; no verdict changed from the third version. Regenerate these files only through that pipeline; do not edit by hand. `status` and `recommended` follow the primary rule, which is the rule the catalog ships under (decision of October 29, 2026); `admissible_alt` and `rule_sensitive` show the alternative.
